# health-risk-prediction
Machine learning classification model that predicts whether an individual is healthy or unhealthy based on health-related data. 

## Dataset
- Source: Novagen Research labs 
- Shape: 9549 rows x 23 columns

## Technologies Used
- Python
- pandas
- NumPy
- scikit-learn

## Workflow
1. Data Cleaning
2. Exploratory Data Analysis(EDA)
3. Feature Engineering
4. Data Preprocessing
5. Hyperparameter Tuning
6. Model Training
7. Evaluation

## Results
### Random Forest Classifier
- Recall: 0.958
- Accuracy: 0.937
